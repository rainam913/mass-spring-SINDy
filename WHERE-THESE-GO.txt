One repair was made to mass_spring_sgn.py on 2026-08-21 before sending.
PySINDy's CustomLibrary applies every supplied function to EACH state variable,
so the constant function was emitting one constant column per state, i.e. two
identical and perfectly collinear columns. The printout showed this directly as

    (x1)' = -0.129 1 + -0.129 1 + ...

The constant is now supplied once, through a separate degree-0 polynomial
library. Every other coefficient is unchanged to the printed digit; the two
half-constants simply add, e.g. -0.129 + -0.129 -> -0.258. No result changes.
